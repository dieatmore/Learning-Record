## 数组合并

### 扩展运算符 ...（推荐）

**返回新数组，不修改原数组**

```js
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];
const arr3 = [7, 8];

// 合并多个数组
const mergedArr = [...arr1, ...arr2, ...arr3];
console.log(mergedArr); // 输出：[1, 2, 3, 4, 5, 6, 7, 8]
console.log(arr1); // 输出：[1, 2, 3]（原数组未修改）

// 合并时插入额外元素
const mergedWithExtra = [0, ...arr1, 'a', ...arr2];
console.log(mergedWithExtra); // 输出：[0, 1, 2, 3, 'a', 4, 5, 6]
```

<br/>

### Array.concat()

**返回新数组，不修改原数组**

```js
const arr1 = [1, 2];
const arr2 = [3, 4];
const arr3 = [5, 6];

// 合并两个数组
const merged1 = arr1.concat(arr2);
console.log(merged1); // [1, 2, 3, 4]

// 合并多个数组
const merged2 = arr1.concat(arr2, arr3);
console.log(merged2); // [1, 2, 3, 4, 5, 6]

// 合并非数组元素（会直接作为单个元素加入）
const merged3 = arr1.concat(10, arr2, [20, 30]);
console.log(merged3); // [1, 2, 10, 3, 4, 20, 30]
```

### Array.push()

如果需要 **直接修改原数组**（而非创建新数组），用 push() 最高效，尤其适合合并大数组（避免创建新数组的内存开销）

```js
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];

// 错误写法：push会把arr2作为单个元素加入arr1
// arr1.push(arr2); → arr1 变成 [1, 2, 3, [4, 5, 6]]

// 正确写法：用扩展运算符展开arr2
arr1.push(...arr2);
console.log(arr1); // 输出：[1, 2, 3, 4, 5, 6]（原数组被修改）

// 合并多个数组
const arr3 = [7, 8];
arr1.push(...arr3);
console.log(arr1); // 输出：[1, 2, 3, 4, 5, 6, 7, 8]
```
