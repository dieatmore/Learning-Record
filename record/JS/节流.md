## 节流

节流（Throttle）: **在指定时间内，无论事件触发多少次，函数只执行一次，强制固定执行频率**

定义：**限制函数执行频率，确保每隔固定时间（delay）执行一次**，避免高频事件（如 scroll、mousemove）导致性能瓶颈

> 类比：水龙头滴水、游戏技能冷却 —— 无论触发多快，都按固定节奏执行

<br/>
<br/>

与防抖（Debounce）区别：
- 节流：固定间隔执行，持续触发也会按节奏执行（如滚动时持续检测）。
- 防抖：停止触发后延迟执行，连续触发会不断重置计时（如搜索框输入）

<hr/>

#### 时间戳版（立即执行，忽略最后一次）

```js
function throttle(func, delay) {
  let lastTime = 0; // 上次执行时间戳
  return function (...args) {
    const now = Date.now();
    if (now - lastTime >= delay) {
      func.apply(this, args); // 执行并绑定this/参数
      lastTime = now;
    }
  };
}
```

> Date.now() 返回的是从 1970 年 1 月 1 日到现在的毫秒数

<br/>

#### 增强版（首尾都执行，更通用）
结合时间戳与定时器，支持首触立即执行 + 末触补执行

```js
function throttle(func, delay) {
  let lastTime = 0;
  let timer = null;
  return function (...args) {
    const now = Date.now();

    // 距离下次可以「立即执行」目标函数，还剩下的毫秒数
    const remaining = delay - (now - lastTime); 

    if (remaining <= 0) {
      // 间隔已满，立即执行
      if (timer) { clearTimeout(timer); timer = null; }
      func.apply(this, args);
      lastTime = now;
    } else if (!timer) {
      // 剩余时间内，设置定时器保证最后一次执行
      timer = setTimeout(() => {
        func.apply(this, args);
        lastTime = Date.now();
        timer = null;
      }, remaining);
    }
  };
}
```
